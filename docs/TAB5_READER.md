# Tab5 Reader 独立阅读固件

开发分支：`codex/tab5-reader-only`。基于已验证的 EPUB、FreeType 流式字体和 Tab5 驱动，
新增独立板型 `m5stack-tab5-reader`，保留原学习/语音固件的构建入口。

## 使用

- 开机进入书架，卡片显示封面、书名和进度；“继续阅读”打开上次阅读的书。
- 底部只有书架、传书、设置三个入口。参考 WhiteOS 的专注阅读与前台传书交互，
  不依赖 WhiteOS 的固件或私有实现。
- 阅读时默认隐藏菜单；点中央显示上下菜单，左侧上一页、右侧下一页。
- 保留横竖屏、字号、行距、边距、纸张背景、夜间模式、亮度和自动休眠；休眠后按电源键重新开机并恢复阅读位置。
- EPUB：`/handict/books`；TTF：`/handict/fonts`。兼容既有 `han_reader` / `display` NVS 设置和进度。
- LXGW 等大字体继续从卡上流式加载，使用 1 MiB、1 KiB 块的有界缓存，避免整份字体载入内存。

## Wi-Fi 与 USB 传书

传书页提供三种方式：

- **局域网**：扫描并选择 2.4GHz Wi-Fi，输入密码后连接路由器；已保存网络可将密码留空。
  手机或电脑连接同一局域网，在浏览器打开设备屏幕显示的 IP 地址，再输入网页连接码。
  网络名称和密码在连接成功后保存；不会在阅读时自动连接。SSID 可手动输入，屏幕列出信号最强的四个网络。
- **热点**：手机连接屏幕显示的设备热点和密码，浏览器打开 `http://192.168.4.1`。
  热点不提供互联网，每次会话重新生成密码和连接码。
- **USB 磁盘**：通过电脑直接管理 TF 卡。

两种网络模式使用同一个网页，可多选 EPUB、TTF 上传并查看进度。
仅选择网络传书时启动 Wi-Fi，停止传书后关闭 HTTP、Wi-Fi 驱动、ESP-Hosted 传输与 C6 电源。
尚未提供 OPDS 或 Calibre。

上传期间暂停阅读并关闭卡上的字体、图片文件。文件先写临时文件，完成格式检查后再更名，
不覆盖同名文件；拒绝目录路径、控制字符、非法后缀和过长文件名。图书上限 128 MiB，
字体上限 64 MiB。中断上传不会把不完整文件加入书架。退出传书自动重扫图书和字体。

USB 模式独占 TF 卡，进入后 COM 口会暂时消失。请在电脑上安全弹出磁盘，再点设备上的
退出按钮；设备恢复 USB 串口路由并重启。USB 启动或退出出错时也保持卡访问暂停，
通过退出重启恢复，避免把电脑与固件同时当作文件系统所有者。

## 本地固件更新

传书网页内可上传独立阅读器的应用 `.bin`，校验镜像头、大小、芯片和项目名后写入另一 OTA 槽。
成功后手动点击网页重启。仅接受项目名 `tab5_reader`，拒绝旧小智应用和整机合并镜像。
首次从旧固件切换请使用串口应用烧录；不改变既有 `han16m.csv` 分区、不格式化 TF 卡、不清空 NVS。

## 构建与结构

使用 ESP-IDF 6.0.2：

```sh
python scripts/build.py m5stack/tab5-reader --name m5stack-tab5-reader
# 新版 P4 硅片：--name m5stack-tab5-reader-p4x
idf.py -p COM7 app-flash
```

输出应用 `build/tab5_reader.bin`。板级硬件初始化位于
`main/boards/m5stack/tab5-reader/`，沿用原 Tab5 引脚与面板识别；阅读核心位于 `main/reader/`，
通过 `Board` 接口访问硬件。独立 CMake 源文件集合和依赖规则排除语音、摄像头、学习页面、
表情、云端激活与对话。Wi-Fi 仍由 P4 通过 C6 / ESP-Hosted 提供，仅在前台传书时启动。

UI 内置字体由 `scripts/generate_reader_font.cjs` 从 Noto Sans SC 生成，保证导入期间即使
卡上字体关闭也能显示中文操作和错误。修改中文界面后需重新生成该字体。

## 验证与当前边界

主机验证：`python -m unittest discover -s scripts/tests -v`；在已配置本机 C++ 编译器的环境下
会编译并测试固件实际使用的文件名策略，包括 Unicode、编码路径穿越、NUL 和类型限制。

`tools/ui-simulator` 中 `reader_ui_sim` 编译实际阅读器页面，验证横竖屏书架、夜间设置、
菜单开关、左右翻页、进度保存和阅读菜单的立即休眠恢复标记，并生成 PPM 截图。模拟器不替代硬件触控、SD、Wi-Fi、USB 或 OTA 验证。

2026-10-27 首版验证记录：92 项主机测试通过，新阅读器 UI 模拟测试与旧阅读器页面回归通过；
ESP-IDF 6.0.2 专用变体规范构建及应用烧录通过。COM7 的 P4 v1.3 / ST7121 实机完成启动、
ST712x 触控初始化、3 本 EPUB 扫描和封面提取、38 px LXGW 加载，以及前台热点启动与停止。
首次实机发现并修复 FreeType 灰度光栅器的栈溢出：界面任务使用与旧阅读路径一致的 32 KiB PSRAM 栈。
应用为 2,136,144 字节，基线 5,626,256 字节，减少约 62%；离线应用就绪时空闲 PSRAM 约 24.58 MB。
这些是首版数值，不是续航测量。用户已确认首版阅读、菜单与传书操作正常。
增加局域网与电源关闭后的修复版已规范构建、烧录至 COM7，正常扫描 3 本书并加载 LXGW，
启动日志确认无线模块供电关闭；应用 2,173,808 字节。92 项主机测试与新增 UI 模拟验证再次通过。
避免在 SDIO 链路首次配置前执行 ESP-Hosted 完整释放，绕过上游未初始化卡结构的释放问题。
局域网浏览器上传、重复开启/关闭网络和休眠恢复尚待用户操作验证；
USB 安全弹出和有效固件 OTA 尚需端到端实机确认。
`m5stack-tab5-reader` 与 `m5stack-tab5-reader-p4x` 均通过规范构建；
工作区最终恢复为 COM7 使用的基础变体并重新烧录。P4X 只有构建验证，尚未上对应硬件。
旧 `m5stack-tab5-han-dictionary` 已通过 ESP-IDF 6.0.2 回归构建。
新增模拟验证覆盖 Wi-Fi 输入、扫描结果选择、密码传递和横竖屏连接页面。

当前继续使用既有 EPUB 文本提取和估算分页；尚不支持 DRM、完整 CSS 排版、PDF、TXT、书签和目录跳转。
阅读中的“屏幕”菜单和全局设置均提供“立即休眠”。休眠先提交阅读进度，停止网络服务并关闭 C6 电源，关闭背光、暂停 LVGL、复位屏幕与触摸、
卸载 TF 卡、关闭 INA226 采样，再通过 PI4IOE 的 PWROFF_PLUSE 执行官方 Tab5 关机脉冲。
如果外部供电仍保持系统供电，则进入 ESP32-P4 深度休眠。按设备电源键重新开机；触摸不会唤醒。
休眠前在阅读页或传书页保留的已打开图书，会在下次开机扫描后恢复。
网络空闲也受休眠时间限制；上传期间延后自动休眠。USB 磁盘模式禁用自动休眠，必须安全弹出并退出。
实际电流、USB 供电与电池供电时的关机和重新开机均须实机确认，不能由此推算续航提升。
电源控制参考 [M5Unified Power_Class](https://github.com/m5stack/M5Unified/blob/master/src/utility/Power_Class.inl)。
